Event Series (Website)

One page for an event you run multiple times, always at the same address

In standard Odoo, every date of a monthly workshop would have its own page, which goes out of date once the event is over. Event Series (Website) gives the whole series a single landing page that can show a description, as well as its current and upcoming dates, with each date linking to its own event page for registration. Share the series link once, in a newsletter or on social media, and it stays working forever.

It includes Event Series, which groups all the dates of an event into a series in the backend.

Fits right into your website

Built from Odoo's own event pages, so your theme styles it too

The events listing page gets a Series filter, to limit events to a series.

Each event's page links to its series page, so users can see other dates easily.

The series listing page shows every published series, along with its next date.

Edit the cover, title, and description for a series in the website editor, as for an event.

Published just like an event

Nothing shows up until you say so

A series has the same Published toggle and Go to Website button as an event, and can be limited to one website. Its landing page shows only the dates a visitor has permission to see: events published on that website.

This module requires Event Series and Odoo's Events app, and installs itself when both are there.
