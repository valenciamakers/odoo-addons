Settings Sort

Alphabetical order for the two lists inside Settings

The list of sections down the left of the Settings screen arrives in an order nobody chose — whichever order the modules happened to be installed in. So does the Technical menu. Finding anything means reading the whole list.

This module sorts both, alphabetically, and keeps General Settings at the top where you expect it.

What stays as it is

Everything inside a Technical grouping keeps the order its author gave it. Only the groupings themselves are sorted, because their order is the accidental part.

The settings of each app are likewise untouched — only the list of apps down the side changes.

Nothing to configure

Install it and both lists are sorted. No settings, and nothing written to your database — the order is applied as each screen is drawn, so removing the module puts everything back exactly as it was.

Each user sees the order that is alphabetical in their own language, with accents and capitals sorted where you would expect them rather than after Z.
