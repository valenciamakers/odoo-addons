Event Registration Deadline

Stop selling a course that has already started

Odoo keeps registration open until an event ends. The only date it checks is date_end. So a nine-to-five workshop is still on sale at 16:55, and a four-week course can be bought in week three with three weeks already missed.

That is right for a conference, where arriving on day two is normal. It is wrong for anything taught. This module closes registration when the event starts, or a set time before it.

One switch, one duration

Settings → Events → Registration carries a switch and a duration beside it. Set 1:30 and registration closes ninety minutes before the start; set 00:00 and it closes as the event begins.

The switch is off by default, so installing the module changes nothing until somebody turns it on.

Per-event override

An event can set its own deadline, beside the seat limit on the event form. An event that asks for one keeps it whatever the global switch says — turning the feature off stops it applying everywhere it was implicit, and nowhere it was asked for.

What it leaves alone

  • A ticket that sets its own Registration End. A date somebody typed is a deliberate choice to allow late registration, and it wins.
  • Multi-slot events are handled per slot, as core handles them, so one late slot does not close the earlier ones — or keep them open.
