Event Registration Deadline

Close registrations before an event starts, not after it ends

In standard Odoo, registrations stay open until an event ends, so people can sign up for a workshop that is already under way, or a course that is half over. Event Registration Deadline closes registrations when an event starts, or a set time before, for every event or only the ones you choose.

Fits right into Odoo

Set it once, and adjust it for any event

Turn it on in the Events settings, with one deadline for every event, such as 01:30 before the start.

Give any event its own deadline, next to its registration limit.

A ticket with its own Registration End keeps it: the deadline only applies where none is set.

Events with multiple slots close each slot the same time before it starts.

Small and focused on purpose

Nothing changes until you turn it on

The deadline is off by default, so installing the module changes nothing. An event given its own deadline keeps it even when the setting is off.

This module requires the Events app.
