Language Sequence

Order enabled languages by hand instead of alphabetically

Odoo lists languages alphabetically by name, everywhere, with no way to change it. This module adds a drag handle to the Languages list so you can put them in the order you want — your main language first, rather than whichever one happens to sort first.

Where the order applies

  • The language selector in your website header.
  • The language dropdowns on users and contacts.
  • The Languages list itself.

How to use it

Go to Settings › Translations › Languages and drag the enabled languages into the order you want. Enabled languages are grouped at the top of the list; a language you enable later joins the end of that group, ready to be dragged into place.

That screen is developer-mode only in standard Odoo, so activate the developer mode first. This module deliberately leaves that as it is.
