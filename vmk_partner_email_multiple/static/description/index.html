Multiple Contact Emails

One contact, all the addresses they write from

People write to you from more than one address — a personal account, a work account, the noreply@ their shop sends order confirmations from. Odoo matches incoming mail on one address per contact, so every other one quietly creates a duplicate contact.

This module gives each contact a list of additional addresses. Mail arriving from any of them lands on the contact you already have.

The comma trick does not work

Odoo's email field accepts a@example.com, b@example.com and appears to tolerate it. It does not: only the first address is ever matched against, and the whole list is then used as the sender header on outgoing mail — which is not a valid address at all.

Additional addresses are kept in their own list instead, so the contact's main address stays exactly what it was.

Merging duplicates keeps their addresses

When you merge two contacts, Odoo keeps one address and discards the other. Here the discarded one is kept as an additional address, so the merged contact still matches mail from either — which is the whole reason you were merging them.

Additional addresses are searchable too: type one into any contact field and the right contact comes up.

Picked the wrong one as the main address? The swap button beside any additional address exchanges the two, and the one it replaces is kept in the list rather than lost.

Nothing is ever sent to them

An additional address means we also know them here, never mail them here. Outgoing mail keeps using the contact's main address, unchanged, so nothing about how your database sends email is altered by installing this.
