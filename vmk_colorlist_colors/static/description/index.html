Custom Colors

Make Odoo's colors fit your own color scheme, everywhere they appear

In standard Odoo, you can give a tag, a kanban card, or a calendar one of eleven colors, but they are fixed, and so are their names. Custom Colors lets you change any color, as well as rename them, from Settings.

An edited color is used everywhere Odoo draws that color: tags, kanban cards, calendars, the color picker, and the website. Records keep the color slot assignment they already had, and show the colors you set.

Fits right into Odoo

Every color picker shows your colors and your names

Pick each color using Odoo's own color picker, right within the list.

Rename any color, and translate the name into each of your languages.

A tag's background and text are worked out from the base color by Odoo's own formulas, just like Odoo's colors.

On Enterprise, dark mode draws your colors the way it draws Odoo's own.

Small and focused on purpose

Reset to Odoo's default colors in one click

The undo arrow next to an edited color resets it to Odoo's default color and name for that slot. Reset to Defaults resets all eleven, as does uninstalling the module. The slots stay as in core Odoo: this module changes how each color looks and what it is called, not how many there are, and the No color slot is not editable.

This module only requires Odoo's base module, and works on both Community and Enterprise.
