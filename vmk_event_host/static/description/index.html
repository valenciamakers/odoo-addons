Event Hosts

Who is actually running the event

An Odoo event records the Organizer, which is the company putting it on, and the Responsible, which is the internal user who owns it. Neither answers the question an attendee asks: who is teaching this?

This module adds a Hosts field to the event — the speakers, teachers or facilitators people will meet in the room.

Contacts, not users

Hosts are contacts, so a freelance teacher or a guest speaker with no Odoo login can be named like anyone else. An event can have several, because workshops and courses are often co-taught.

Where it shows up

  • On the event form, beside Responsible and Organizer.
  • As an optional column in the events list.
  • In the search panel, both to search by and to group by Host. A co-hosted event appears under each of its hosts.
  • In the chatter: host changes are tracked, as Responsible and Organizer changes already are.

Small on purpose

The module adds one field and the views to use it. It changes no core behaviour, touches no website page, and depends on nothing but Events.
