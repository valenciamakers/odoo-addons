Protect Language Edits

Keep your changes to language settings when Odoo updates

In standard Odoo, every module update resets the language settings to the default Odoo values, so a renamed language or a changed date format is quietly overwritten. Protect Language Edits keeps your changes: any language you edit will be protected from updates.

Fits right into Odoo

Edit language settings as usual, and your changes stay

Editing a language's name, codes, or format settings protects it automatically.

A Protect From Updates switch on the language form shows the status, and disables protection.

Languages already enabled are protected when you install the module.

Translations still update as usual; only the language settings are protected.

Small and focused on purpose

Nothing changes for languages you have not edited

Disabled languages, and languages you enable but don't edit, keep receiving regular Odoo updates. A protected language will no longer receive any corrections to its settings; disable protection to receive updates again.

This module only requires Odoo's base module, and works on both Community and Enterprise.
