Apps Menu Sort

List your apps alphabetically, in the apps grid and everywhere else

In standard Odoo, apps are listed in whatever order they set for themselves, so the apps grid reads as no order at all. Apps Menu Sort lists them alphabetically, with Apps and Settings kept at the end.

Before and after

The same apps, in standard Odoo and sorted

Standard

With Apps Menu Sort

The apps grid, the navbar apps menu, and the command palette all use the same order.

The order follows each user's own language setting, with accented names sorted correctly.

Apps and Settings are kept at the end of the list, where Odoo puts them.

Nothing is stored; uninstall the module and the original order returns.

Small and focused on purpose

Only the order of your apps changes

The menus inside each app keep their own defined order. On Enterprise, a user who has rearranged their apps grid keeps their own arrangement.

This module only requires Odoo's base module, so it works with any set of apps, on both Community and Enterprise.
