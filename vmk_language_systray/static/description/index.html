Language Systray

Switch your own backend language without leaving the page

Changing your interface language normally means Settings → your profile → a form field → save. This adds a globe icon to the systray, next to the company switcher, listing every active language. Pick one and the backend reloads in it.

Yours only, backend only

It writes only the language of the user clicking it, and only the backend interface language. It never touches the website's frontend language, and it never appears at all in a database with a single active language.
