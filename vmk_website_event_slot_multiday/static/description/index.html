Multi-Day Event Slots (Website)

Publish weekend retreats, overnight hackathons, and multi-day courses as slots

In standard Odoo, an event slot must start and end on the same day, so it can never span more than one. Multi-Day Event Slots (Website) gives each slot a start date and an end date, and displays both to website visitors when they select a slot. It includes Multi-Day Event Slots, so one module covers the backend and the website.

Fits right into Odoo

Odoo's own features work as before, just with longer slots

Website visitors see a multi-day slot's start and end dates when they select it.

The slots calendar view displays multi-day slots spanning all days.

An attendee's registration ends when the slot does, so calendar links include all days.

Mail scheduled for after the event is sent once the slot ends.

Small and focused on purpose

Nothing changes for single-day slots

Single-day slots look exactly as they do in standard Odoo, on the website and in the backend. A multi-day slot is listed under its first day, with its start time, the same way Odoo lists every slot, and its end date appears once a visitor selects it.

This module requires the Events app, and includes Multi-Day Event Slots. For the backend alone, without the website, use Multi-Day Event Slots on its own.
