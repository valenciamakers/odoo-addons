Multi-Day Event Slots on the Website

Show visitors both days of the slot they pick

When a visitor picks a slot on the event page, Odoo prints the slot's start date and time and its end time alone, because a standard slot never leaves its day. For a slot from Friday evening to Sunday afternoon, that reads as one evening.

With Multi-Day Event Slots, this module gives the end its date too: Fri, Oct 9, 2026, 6:00 PM - Sun, Oct 11, 2026, 1:00 PM. Slots within one day read exactly as before.

Installs itself

It depends on Multi-Day Event Slots and Website Events, and installs automatically once both are present. It adds no settings and no text of its own.
