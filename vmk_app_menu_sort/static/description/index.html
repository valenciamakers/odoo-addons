App Menu Sort

List the apps alphabetically, with Apps and Settings kept at the end

Odoo shows your apps in the order their sequence numbers happen to give — a number each app's own module picked for itself, which is nobody's idea of an order. This module sorts them alphabetically instead, and keeps Apps and Settings at the end where you expect to find them.

Where the order applies

  • The app grid on the main page.
  • The apps dropdown in the top bar.
  • The command palette, before you type a search.
  • The “Go to your Odoo Apps” dropdown on your public website.

Nothing to configure, nothing to maintain

Install it and the order changes. No sequence numbers to edit by hand, and nothing that a module update can quietly undo — the ordering is applied when the menu is loaded rather than written into your data.

Each user sees the order that is alphabetical in their own language, accents and capitals sorted where you would expect them rather than after Z.

If you have dragged your apps around

Odoo Enterprise lets each user rearrange their own app grid by dragging, and that personal order still wins — this module sets the starting point, not the last word. If you would rather everyone started fresh from the alphabetical order, an administrator can run the Reset per-user app grid order action once. Installing the module never touches anyone's saved layout on its own.
