Apps Page Sort

Order the Apps page by the name on the card

The Apps page looks unsorted because it is ordered by a name it never shows you: the module's technical name. Employees is filed under hr, Invoicing under account, Discuss under mail. Nothing on screen explains the order.

This module sorts the page by the name written on the card, which is the one you are actually reading.

Both ways of looking at it

  • The Apps page in its usual card view.
  • The same page switched to list view.

Applications stay ahead of technical modules, so clearing the Apps filter still gives you something sensible rather than several hundred entries in one run.

Nothing to configure

Install it and the page is sorted. No setting, no data changed, and nothing written to your modules — the order is applied when the page is drawn, so uninstalling puts everything back exactly as it was.

Module names are translatable, so each user sees the page sorted in their own language.
