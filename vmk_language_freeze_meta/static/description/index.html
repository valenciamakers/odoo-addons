Language Metadata Protection

Stop Odoo updates reverting your edits to language metadata

Odoo ships its languages as module data and re-applies them every time a module is updated, so any edit you make to a language quietly disappears. Rename English (US) to English, and the next update puts it back.

This module makes those edits stick.

What Odoo resets, and this module keeps

  • The language name, as it appears everywhere you offer a choice of language.
  • Its ISO code, and the code used in website URLs.
  • Date and time formats, the first day of the week, and number separators.

It protects the language record itself, not your translations. The two are unrelated, and translation updates carry on exactly as before.

Nothing to set up

Installing it protects the languages you have enabled. After that, a language is protected the moment you edit one of its fields — you do not have to remember to flag anything, and simply enabling or reordering a language does not count as a customisation.

A Protect From Updates toggle on the language form shows the state and lets you switch it off again, handing that language back to Odoo.

The trade

Protection applies to a whole language record, because that is the only granularity Odoo offers. A protected language also stops receiving genuine Odoo corrections — a fixed date format, say. That is why the languages you have not enabled are deliberately left alone to track Odoo.
