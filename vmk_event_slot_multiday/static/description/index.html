Multi-Day Event Slots

A slot that runs from Friday evening to Sunday afternoon

An Odoo event slot is one date and two hours on it, so it can never leave its day. A weekend retreat, an overnight hackathon, or a two-day course offered on several dates cannot be a slot.

This module adds an End Date to each slot. Leave it as it is and the slot is exactly what it was; set it to a later day and the slot runs until then.

Everything follows the real end

  • The slot calendar draws the slot across all its days.
  • An attendee's registration ends when the slot does, so their calendar links and any mail scheduled after the event go out at the right time.
  • The slot is still kept inside its event's dates, by Odoo's own check.
  • A multi-day slot is named by both its days, such as Oct 9, 2026, 18:00 - Oct 11, 2026, 13:00.
  • Moving a weekend slot to another date keeps it a weekend.

Small on purpose

One field, and a Date range row on the slot form so both days can be seen and edited. Slots within one day behave exactly as before. It depends on nothing but Events; with Website Events installed as well, the companion module Multi-Day Event Slots on the Website installs itself and shows both days to visitors when they pick a slot.
